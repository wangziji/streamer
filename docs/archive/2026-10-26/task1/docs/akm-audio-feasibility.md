## 建议架构及待验证边界

以下是工程建议，不是已完成的设计：

```text
Android USB 主机 / 外部电脑（二选一）
  → USB 音频接收桥 → AK4191EQ → AK4499EXEQ
  → I/V、低通滤波、输出级 → 受控静音 → XLR / RCA

独立控制器 → 音量限制、配置、复位、时序、故障静音
```

- USB 桥候选须核查其输出格式、时钟主从、采样率系列及实际固件能力；AK4191 的接口模式、最高速率所需通道安排须用正式数据手册验证。
- 内部 Android 与外部电脑不能无控制地共用 USB 主机连接。可比较 USB 上游切换或两个接收链路；切换过程必须先静音，USB-C 角色和 VBUS 防反灌另行设计。
- 音量至少分为 App/系统音量、数字前端衰减、可选模拟衰减三个层次。应先建立唯一的设备主音量状态，再决定数字、模拟或混合实现，避免旋钮、App 和电脑音量各自改变增益。
- AK4191 的衰减寄存器、复位默认音量、软静音、DSD 直通与音量旁路行为尚未从本次可访问的官方完整数据手册核实。**不得据二手说明默认原生 DSD 可以安全调音量。** 首版已允许 DSD 转 PCM，但仍须验证实际转换链路和增益。
- 独立控制器与硬件静音属于纯后级直连的候选保护架构；心跳丢失、控制总线卡住、欠压、时钟丢失等默认状态与检测边界须逐项设计。软件静音、DAC MUTEN 和模拟断开不能互相替代全部故障覆盖。
- 分离主控/USB 数字板与 DAC/模拟板便于定位干扰；是否电气隔离需测量和接口预算支持，不能把分板自动等同于隔离。
