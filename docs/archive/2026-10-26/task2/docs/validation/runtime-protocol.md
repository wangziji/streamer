# Task 2定义：纯电池续航与电量测量规程

版本 T2-2026-10-26-v2。`execution_status=not_run`。本文件供Task 9执行，未列已存在仪器/样机；型号、版本、真实介质和器材清单尚未核实。计算见[能量包](../engineering/battery-energy.md)，数据字段见[预算CSV](../engineering/power-budget.csv)。设计计算不代替3600秒实际播放。

## 入口与固定条件

1. Task 3电源包、Task 6保护/关机、Task 7输出限值已审核；Task 9入口样机完成装配/上电前检查并获准限流首次上电。先用假负载/音频分析仪；本规程不授权直连纯后级、不授权采购或刷写介质。
2. 创建独立 `docs/evidence/runtime-<date>-<revision>/`，事先固定硬件/电池包P/N、标签和datasheet版本、BMS/SMBus文档、固件/Android镜像/App摘要、主板修订、屏幕型号、存储和所有外设。未经关闭的电池全工作电压/峰值/温度资料缺口必须先关闭。
3. 环境25±2°C；箱盖、通风、风扇策略与正常使用一致，记录室温及电池/转换器/主板温度。首轮该条件结果不外推至其他环境；最终使用温度边界由Task 3冻结并分别复测。禁止用拆壳/额外风扇条件冒充整机。
4. 屏幕全程常亮、禁休眠/自动亮度。以面板中心200cd/m²为本轮目标，记录仪器、实测亮度、系统设置百分比和画面/界面；屏幕不能达到该亮度或用户批准另一亮度时，先更新条件及预算再执行，不能途中变暗取通过。
5. 正常组固定Wi-Fi 5GHz、RSSI目标−55±5dBm并记录实际值（若不支持先改版规程），禁系统/App后台更新；用局域网固定服务端循环无损播放列表，记录服务端版本、曲目内容SHA-256、PCM 24bit/96kHz、实际USB输出及是否重采样。云流媒体另做源组，不能用LAN成功替代。格式不被平台支持时记blocked，不默降格式。
6. 输出首组XLR立体声4Vrms、每声道差分10kΩ非感性负载；RCA另组2Vrms、每声道10kΩ。上述是比较起点，Task 7须先审核这些电平/负载及安全音量。正常组使用固定音乐/电平分布，记录数字音量/限幅和真实RMS；另用1kHz校准信号设定电平，不能把音乐一直当满幅正弦。最坏连续负载组按Task 7审核的信号执行，保留完整负载/失真证据。
7. 每组记录USB桥实际格式、负载、CPU利用率/频率/温度、存储和网络活动。用实测发现的最耗电正常模式作追加组（如高采样、显示/CPU负载或外置存储）；不因预算表中有768k字段就声称整机能播放该格式。独立PC DAC组记录主控关闭，屏幕状态单列，不能替代屏幕常亮主控播放组。

## 仪器、接线与原始记录

- 电池包输出端之后、板级分支之前放校准功率分析仪/四线分流器，记录仪器/量程/校准日期/零偏/精度/插入压降。多轨测量注明每个探点及参考地，负轨电流按取电幅值记录。测量插入压降不得改变低压保护行为；超预算先修复接线。
- 电池包V/I、各负载轨V/I目标同步≥10Hz，温度/SMBus SOC/容量/状态≥1Hz；记录真实采样间隔、时钟同步误差和丢样。开机浪涌/轨跌落/切换用示波器≥1MS/s起步，并以最短待测事件保证足够带宽/采样率/预触发窗口；10Hz日志不证明无微秒级掉电。
- 充电输入、PC USB VBUS和Pi相关外部输入分别测电压/电流，双向量程覆盖反灌。数据记录优先电池隔离供电或隔离链路，USB调试口、分析仪地、HDMI、网口PoE、串口均检查是否形成意外供电路径。外接电脑仅传音频和必要连接检测。VBUS检测支路必须与系统轨/电池充电路径隔离，分别测总端口、检测支路及可能流向系统轨或电池的电流；检测支路电流上界及隔离证据须在Task 3/5接口设计审核后、测试前冻结。不得把检测支路例外扩展到USB桥或其他运行负载供电。
- 暂定功率闭合：比较包端输入积分与逐支路输入/输出加损耗，按仪器合成不确定度解释差异；不得要求理论负载总和与包端完全相等。不能测全轨时列出缺失轨及其误差上界，无法区分外供/损耗时结论为inconclusive。LDO地电流、包内BMS自耗和支路未覆盖项分别核对。

## 充满、断外供及计时

1. 按准确包型官方充电流程充满；记录充电上限/终止电流、SMBus及实际端V/I、静置时间与起始温度。RRC2054和2054-2充电上限不同，禁止互用。SOC=100%不是独立充满判据；无官方终止条件则不进入正式测试。
2. 先稳定播放至少5分钟，建立日志/校准，充电功率路径物理断开或经审核隔离后验证。充满后的预播放能量损耗记录在案，采用断外供时状态作为计时起点，不回补计算出的分钟数。插适配器但纯电池模式的路径阻断验证单列附加组，不取代物理断开基准组。
3. 断开后分别检查外部供电路径与VBUS检测支路。对适配器、其他外输入及PC VBUS流向系统轨或电池的供电路径，理想供电电流为0；只要检出向系统轨或电池供电，判fail。必要连接检测允许消耗正向电流，但仅限经审核的独立检测支路，其实测电流连同不确定度上界不得超过已冻结的检测支路电流上界，并须提供该支路不能向系统轨/电池送电的隔离证据。超限或确有供电路径判fail；检测预算/隔离证据未冻结、只有总端口读数而不能证明去向时记inconclusive。不得仅从总端口电流减去预设检测预算，来推定没有给系统供电。对禁止供电路径低于分辨率的读数，只可写“未检出，上界x W/x Wh”，不能写绝对0；上界足以影响3600秒判定时改测量方案并记inconclusive，禁止用减去外供能量来挽救时间通过。总端口及检测支路原始数据均保留，获准检测耗能单列，不当作供给系统负载的能量，也不增加测得的纯电池播放时间。
4. `t0`为外供隔离已确认且稳定可播放的第一个同步单调时间戳。持续记录屏幕/音频/电源。若有掉音、重启、自动降亮度或异常重连，立即记录首次事件，不能忽略或重置时钟后当成同一成功运行。
5. `t1`为受控低电静音/关机开始前最后持续可播放时刻；计时不包含静音后的关机预留。`duration=t1−t0`。若提前故障则以首次故障时刻结束并判fail。不得运行至BMS硬切断以延长续航；达到设计温度/欠压保护边界按审核流程立即受控关机。
6. 单独记录t1后静音、数据保存、主控退出、I/V与EX等电源关闭波形、总关机时间及包端能量。检查储能足以完成审核时序；本包60s/0.82086Wh只是分配。正常关机成功不替代突然电池断开的失电保护验证。

## 分组、判据与重复

正式正常组XLR与RCA各3次完整充放运行，轮次在测试前固定；每轮重新按官方流程充满并恢复环境。所有已选外设、最耗电正常格式和独立PC模式按审核矩阵补组；未决功能保持pending。基准新包试验不证明寿命末期：需准确包型在实际倍率/温度下的可追溯衰减依据、实测老化包或经审核的等效放电能量/内阻模型；实验室等效源只验证电源/控制，不能标成真实老化电池续航通过。

每次通过须同时满足：实际连续可播放时间的**不确定度下界≥3600s**、固定屏幕/音源/网络/负载条件成立、无欠压重启/提前掉音/外部供电、温度与电压电流始终合规，并成功完成受控关机与保护时序。音频掉音判定的幅值/持续时间检测限、时钟误差及外供可检出上界须在测试前结合仪器冻结；未冻结或记录缺失记inconclusive，不得宣称无掉音。三次全部通过才写该组bench结果，不能选最好一次。整机system验收仍按Task 9/10，不因本规程一个组通过自动放行。

测试状态只用not_run/blocked/inconclusive/fail/pass，并说明判据。失败保留首次原始日志及修复版本，不能用重跑覆盖失败。实际文件与结果存放新run目录，本Task 2不创建伪装成真实run的空测量CSV。

## 失电与充电播放边界

拔适配器不会切断仍在线的电池，不能代表电池故障。电池/BMS意外切断、连接器脱落、双输入失效和板内路径失效须在Task 3/6/9用限流等效电源、可控断开装置及假负载单独注入，保留各轨/静音示波波形；不得故意过放、短路或损坏真实电池。I/V先于EX失电遵循本地[AK4499EX p29 §9.7](https://www.akm.com/content/dam/documents/products/audio/audio-dac/ak4499exeq/ak4499exeq-en-datasheet-myakm.pdf)。

低电量允许充电输入参与的组另测电池净电流、输入功率、发热与切换音频；该组不能用来满足纯电池3600秒。电池优先占比、充电净功率和阈值由Task 3完成后再扩展规程。
