# 音频验收基线

用户已确认以下分层要求。它们是本项目的目标，不是当前工程的实测结果；本文件尚非完整测试规程。

## XLR 指标

| 层次 | 信噪比（A 计权） | THD+N |
| --- | --- | --- |
| 原型调试门槛 | ≥115dB | ≤0.001%（约 −100dB） |
| 最终最低验收线 | ≥123dB | ≤0.0002%（约 −114dB） |
| 对标设计目标 | ≥128dB | ≤0.0001%（约 −120dB） |

调试门槛仅用于阶段性检查，不能代替最终验收。最终最低线未达到时记录为未通过，由用户决定继续改板或调整目标，不得自动降低标准。未达到对标设计目标的差距也应明确报告。

2026-10-24新增电池供电需求后，纯电池播放与低电量充电播放须分别测量并报告上述指标；不得自动放宽充电播放时的既定最低线。纯电池模式还需确认充电功率路径实际断开；模式转换过程另验爆音、重启和电压稳定，不能只测转换前后稳态。

## 正式测试前须明确

- 额定输出电平、测试负载和输出模式。
- 数字输入路径、采样率、信号频率、幅度与 DAC 滤波设置。
- THD+N 测量带宽及计权；SNR 的参考电平、静音状态与防自动静音方法。
- 音量位置、常用音量区间及左右声道匹配要求。
- RCA 独立指标、频响、串扰、输出阻抗和直流偏置限值。
- 启动、重启、掉电、音源/格式切换及控制失效时的静音、音量限制与瞬态验收条件。
- 运行时网络、显示屏、电源负载与热稳定状态。
- 仪器残余噪声与失真、接线方式、测量不确定度及通过判据；测量能力不足时记录为无法验证。

## 对标资料

- [Eversolo DMP-A6 Gen 2 官方手册](https://music.eversolo.com/dmp/instruction/EVERSOLO-DMP-A6-Gen2-User-Manual-v1.0.pdf)：XLR SNR >128dB（A 计权），THD+N <0.000092%。
- [RME ADI-2 DAC FS 官方介绍](https://rme-audio.de/adi-2-dac.html)：123dBA、THD+N −116dB。

厂商数值仅作目标参考；不同测试条件下不能直接排名。整机必须验证实际音源到模拟输出的链路，不能以 DAC 芯片规格或局部测试替代整机结果。
