## 归档范围与资料使用

本次上传设计/进展文档、规格来源和版本manifest、元件清单及文字校验证据。原厂18份PDF及1份文档源文件继续保留在本地规格库，本快照不再分发原厂原件；对应Markdown链接转换为manifest中的官方来源，转换记录与源/归档SHA256保存在archive-manifest.json。

后续电路设计仍须先从官方来源取得并本地保存确切版本的完整规格，核对manifest的SHA256，再按本地文件页码引用。网页链接、产品简介、论坛或搜索摘要不能代替这一门槛；官网文件更新导致哈希不同应记录新版本并评审，不能假称原版本。

本快照没有携带KiCad工程、导出网表XML或从规格提取的全文。文字证据中提及的未携带文件，其摘要用于标识本地原件，不代表仓库内已有这些原件。设计规则中引用的工具/skills需由执行环境提供。

仓库原有需求和可行性文档保留为历史资料；当前范围以本快照需求记录及其明确批准状态为准。
