## OPA1612：有 AKM 官方推荐依据，仍需核算整个模拟链

现有 [AK4191/AK4499EX 官方应用笔记](https://www.akm.com/content/dam/documents/products/audio/audio-dac/ak4191eq/ak4191eq-en-designtransition-myakm.pdf) 第20页 §7.2 明确推荐 OPA1611/OPA1612，依据为带宽、压摆率和输入电压噪声；但该段实际性能测试表述指向 **OPA1611**，不能转写为 OPA1612 在本项目已达标。

- OPA1612 手册第4-6页 §6.3-6.4 给出供电、输入共模、输出摆幅、电流及噪声条件。它是双极型输入、轨到轨**输出**运放，不能视为轨到轨输入；应逐级检查 DAC 的共模、I/V 输出直流位置及峰值摆幅。
- 第15-16页 §8.2 要求同时考虑电压噪声、电流噪声、源阻抗和反馈网络。芯片的典型噪声、THD+N 数字不是整机指标保证。
- 第17页 §8.4 指出低闭环增益与较大容性负载可能降低相位裕度、引发峰化或振荡。I/V 反馈、电路寄生、滤波负载及输出线缆均需稳定性验证；“单位增益稳定”不等于任意跨阻结构稳定。
- [AK4499EX 数据手册](https://www.akm.com/content/dam/documents/products/audio/audio-dac/ak4499exeq/ak4499exeq-en-datasheet-myakm.pdf) 第47页 §10.4 给出差分电流输出和外部 I/V 关系。需要联合 AKM 应用笔记第19-22页 §7.1-7.7 核算转换后的幅度、直流偏置、低通与差分合成，不能直接把参考电路输出接至目标 XLR 电平。

**结论：**可保留为有官方依据的 I/V/滤波候选。尚未证明本项目 XLR 负载能力、输出电平、音量调节、直流安全、噪声及失真目标；不能因为选用该运放就宣称已满足纯后级直连。

## TS3USB221A：只选择 D+/D−，不是完整 USB 主机切换方案

- 第3页 §4 引脚及第12页 §7.1-7.2 框图确认它是双向、双通道 SPDT 数据开关，面向 USB 2.0 High-Speed 480Mbps。它既不是 USB 控制器，也不提供 USB 3.x SuperSpeed 数据通道。
- 第13页 §7.4 真值表：OE 为高时全部断开，OE 为低时由 S 选择一路。第15页 §8.2.1 要求控制脚有确定电平，避免浮空造成错误选通。控制策略应先静音、断开数据路径，再选择/使能及重新枚举；这是待验证的系统策略，不是器件自动实现的协议管理。
- 第3页引脚表没有 VBUS 路径。因此内置主机与外部 PC 的 VBUS **不能直接相连**；必须另行设计电源选择、防反灌/隔离、有效性检测及自供电 USB 设备的连接行为。本器件不提供 USB 电气隔离，数据关闭也不等于断开地线。
- 第4-5页 §5.3/5.5 给出推荐工作条件及掉电漏电测试范围；不能把这些条件扩大解释为完整整机的所有掉电顺序均安全。
- 第16页 §8.4 给出差分布线、参考平面及布局要求。应通过实际连接器、开关、保护器件和线缆组合的信号完整性、枚举、掉线/重连测试；器件级 HBM/CDM 指标不能代替外露接口的系统 ESD 验证。

**结论：**若两路主机共用一个 USB 2.0 音频设备，该器件用途匹配，须与独立 VBUS 管理一起评审。若目标变为 USB 3.x，或需要两个主机同时连接同一设备，则此方案不匹配。外部 PC 的 USB DAC 输入角色与内置 Android 的 USB 主机角色必须分别定义。

## STM32G0B1CBT6：控制功能充足，当前有功能余量

- 第11-12页 §2/表2支持 GPIO、定时器、ADC、I²C/SPI/UART 和看门狗等控制用途。第161页 §7 订货规则确认：`C` 为48脚、`B` 为128KB Flash、`T` 为 LQFP、`6` 为 −40至85°C环境等级。不要把系列标题的“最高512KB”误写成该候选容量，也不要混用带 `N` 后缀的引脚分配。
- 第38页图5区分 LQFP48 的 GP 与 N 版；第47页起表12及后续复用表需落实控制口、编码器、SWD/复位及监测信号的引脚分配，再判断48脚是否合适。
- 第17页 §3.7.1 和第93页 §5.3.14 给出供电及 I/O 约束。5V 容忍不能泛化到所有引脚和所有供电状态；驱动继电器、功率开关或监测模拟电源需要相应接口电路。
- 第30页 §3.18.5-3.18.6 提供独立与窗口看门狗，可用于故障恢复。看门狗不自动证明安全静音；复位、欠压、固件失控和 Android 无响应时的输出状态，应由系统默认电平、硬件使能链及实际故障注入验证。
- 其 USB 是 Full-Speed（第1页、第11页），不是 High-Speed 音频接口替代物；控制 MCU 不应被默认为替代 XMOS 的高码率音频桥。内置12位 DAC 也不替代 AK4499EX 音频链。

**结论：**用于电源时序、静音联锁、USB 选择和实体控制的能力充足；仅做这些任务时，USB/UCPD/FDCAN 等资源属于功能余量，可能过度配置。完成 I/O 清单、固件与升级预算后再决定保留该型号或缩小，当前不选定替代型号。

## 选定前的必要证据

1. 模拟链：基于已归档 AKM/TI 资料完成共模、峰值、噪声、稳定性与目标负载核算，再做仿真和实测。
2. USB：明确两个主机与音频设备的拓扑，单独评审 VBUS/防反灌，验证选择、静音、重新枚举及所有供电组合。
3. 控制：完成引脚、控制权限、上/掉电、复位与失联状态表；后续固件设计还需归档对应 ST 参考手册及勘误，当前完整 datasheet 不替代这些资料。

本文不指定电阻电容值、不修改 CAD，所有电路级验证仍待执行。
