## 已核实：时钟域及同步关系

1. **两颗 AKM 之间始终需要同步的时钟。** AK4191 MCLKI 与 EX MCLK 可以不同频，但必须同步；异步模式分离的是输入音频与本地时钟，不能用两颗互不相关的振荡器分别驱动两芯片。[AN p3 §4.1(2)、p6表4]
2. 同步模式 `DSYNCE=0` 为默认；PCM slave 时 MCLK、BICK、LRCK 同步。异步模式 `DSYNCE=1` 下 BICK 与 LRCK 仍同步，但不要求它们与 MCLK 同步。[D4191 p53 §9.1.3.1、p55 §9.2.3.1]
3. 异步模式限44.1kHz和48kHz基频系列，`FS32K=0`；基频有效窗口分别为43.7～44.5kHz、47.6～48.4kHz，超窗可能产生 pop。手册建议 `SLOW=SSLOW=0`、DSD `DSDD=0`。[D4191 p53 §9.1.3.1]
4. MCLK须连续；改变输入频率时须使 `PMPLL=0`。MCKS需与实际频率对应；例如 `MCKS=01` 对应22.5792MHz或24.576MHz，`MCKS=10` 对应2.8224MHz或3.072MHz（均 `FS32K=0`）。[D4191 p54表7]
5. EX `OSR128` 时 BCK为5.6448/6.144MHz，可配22.5792/24.576MHz MCLK（比值4）；`OSR256`需不同BCK比值。改变EX MCLK须在Power Down、Standby或Mute状态。[DEX p23 §9.2表3]
6. 直接用45.1584/49.152MHz驱动EX MCLK不在本手册范围；EX高频MCLK范围上限27.648MHz。[DEX p16 §8.3] CCHD-957虽然提供上述高频型号，也提供22.5792/24.576MHz型号；不能因器件系列相同就认为频率可互换。[OSC p1～2]

## 已核实：音量、复位与静音

- AK4191 `ATTL/R=FFh` 是0dB默认，`00h`才是Mute；PDN拉低会恢复FFh。`RSTN=0`软复位保留控制寄存器。**硬复位后不能沿用“之前已经小音量”的假设。**[D4191 p78 §9.6、p105 §9.18.3]
- AK4191数字音量为0.5dB步进至−127dB；默认0dB→Mute转换约92.5ms（44.1kHz基频），并非立即静音。复位期间写入音量可在释放后生效。[D4191 p78表26～27]
- DSD `DSDD=1` 为音量旁路，数字衰减失效；pin control模式衰减固定0dB。首版若依赖AK4191主音量，必须使用寄存器控制并禁止该旁路；DSD转PCM仍需核查实际上游增益。[D4191 p53 §9.1.3.2、p78 §9.6；后半句为设计建议]
- EX寄存器默认 `MUTEN=0`（静音），但也默认 `STME=0`（Mono）；PDN恢复所有寄存器默认值。不能只释放PDN后直接播放。[DEX p41～44 §9.11～9.12]
- EX的PDN边沿即使输入零数据也可click；MUTEN变化后内部动作最长77µs；电源关闭时不得输入时钟、数据和模式信号。[DEX p31图14注3、7、8]
- 官方建议连接两颗器件的MUTEN；上游异常状态可进入AK4191 AMUTE。改变EX MCLK、BCK和OSR时MUTEN保持低，稳定后才释放。[AN p4 §4.1(4)～(5)]
- `SMUTE`、数字零数据、芯片MUTEN和外部模拟静音覆盖不同状态，不能相互替代。尤其参考示例“零调制信号”仍可能含带外噪声。[AN p8、p11注2；其系统含义为设计判断]

## 已核实：I/V电气及上掉电约束

- EX为全差分电流输出；参考条件下差分电流72.8mApp典型，输出负载电容上限5pF。I/V必须紧邻，不能把IOUT先引到远处连接器。[DEX p11 §8.1；布局建议为推导]
- 参考I/V采用360Ω反馈时，单相约4.6Vrms、差分合成约9.2Vrms；并非已经得到最终XLR额定电平。输出极性电流不能直接相加，应在I/V后电压合成。[DEX p47 §10.4；AN p21 §7.6]
- 参考图31使用±15V运放电源；这是示例而非全部可能实现的强制电压。最终运放须验证输出摆幅、电流、噪声、带宽、稳定性及限流；不能先定低电压再假定图31摆幅仍成立。[DEX p47图31；选型要求为设计建议]
- I/V运放必须在EX已带电期间才上电、且先于EX掉电。违例可能损伤EX输出引脚；手册给出无法遵循时的6～7V齐纳保护建议。[DEX p29 §9.7图13]
- 示例外部晶体管静音接于I/V之后，手册明确提示可能令THD+N恶化约3dB。这不是任何静音器件都必然损失3dB，应比较所选实现的实测结果，不能忽略它对最终门槛的影响。[DEX p50 §10.5图35]
- `SC=0`测量模式是模拟指标的规定条件，`SC=1`不保证同样指标；验收必须固定设置。[DEX p28 §9.6]

## 控制状态机输入建议

下表为待审核的整机策略，并非声称芯片已经实现整机保护。硬件PG/欠压和静音路径应覆盖MCU/Android失效；具体器件、时间余量和故障覆盖尚未选定。

| 状态 | 应保持的约束 | 进入下一状态前的证据 |
| --- | --- | --- |
| 断电/复位 | 模拟输出默认隔离或静音；PDN受控；禁止向未供电域灌入信号 | 电源域及防反灌条件成立 |
| 电源建立 | 4191接口先于/同时于1.2V内核；EX先于/同时于参考；I/V后于EX | 各域PG、参考稳定和实际延迟核查 |
| 配置 | AK4191释放PDN后先写Mute及所需音量；EX保持静音；配置DSEL、接口、OSR、时钟、DSD策略 | 关键寄存器读回、音量限值有效；不能用Android启动完成代替 |
| 锁定/稳定 | 连续MCLK及必要音频时钟已供给；PLL释放后至少5ms再释放RSTN；RSTN生效需3～4/fs | 输入模式、PLL及时钟状态满足；执行对应Case的零数据等待 |
| 播放 | 解除芯片静音后再经受控步骤接通模拟输出 | 音量、输出选择、故障检测全部就绪 |
| 换源/换格式 | 先零数据/数字衰减及模拟静音，再按Case复位、切换；不能仅等一个固定短延迟 | Case1建议额外10ms零输入完成比率计算；Case2使用PLL稳定等待等对应条件 |
| 故障/关机 | 先模拟静音，关闭I/V后才关闭EX；隔离仍带电的USB、MCU信号 | 即使拔掉外置适配器仍满足时序，需储能/放电及硬件欠压预算 |

时序证据：D4191 p98～101 §9.17、p105 §9.18.3；AN p8 §5.1.2、p11～12 §5.2.2；DEX p29～31 §9.7～9.8。AN示例零数据等待还包含 `4096×256/FCKB + 77µs`，不能把77µs或5ms当作全部切换时间。

## 需要继续关闭的证据缺口

1. USB桥具体型号、固件、音频接口格式/电平以及能否接受本地共同基准，决定候选A是否成立。
2. D4191 p54～55称PLL不稳时BCKO低，p104 §9.18.2又描述Unlock时BCKO继续；在制造商澄清前，不能以“BCKO停止”作为唯一解锁检测或保护触发。
3. 电源电流预算、各域容差和最坏热耗散、参考去耦、运放型号及PG/欠压控制器均未冻结；典型参数不能当作整机最坏值。
4. 测量条件需覆盖完整音量/输出/静音链路；不得把EX典型135dBA、−124dB的指定测试条件直接写成整机保证值。[DEX p11 §8.1]
