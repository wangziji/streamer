# 设计澄清记录

## 已确认

- 首版聚焦音乐播放与模拟输出，视频及智能家居功能后续考虑。
- Android 主控承担音源、协议、播放软件、GUI 和操控；树莓派优先，允许评估更合适的平台。
- 自研电源、时钟处理、DAC、滤波及模拟输出电路；PCB 使用 KiCad。
- 电路设计只使用 `docs/specs/` 本地归档的原厂官方规格作为依据；所有核心器件先归档准确型号的完整spec，再设计。禁止以论坛、非官方文章、第三方镜像或搜索摘要作为电路依据。缺失资料阻塞对应设计，不能用brief冒充完整datasheet。
- 必须支持纯后级直连，提供平衡 XLR 与 RCA，默认选择一路输出。
- 功放和音箱型号未定；启动、重启、掉电和控制失效时静音，以及开机音量上限纳入验收。具体保护实现尚未决定。
- 对标 Eversolo DMP-A6 Gen 2，具体体验和性能指标待拆解，不能默认要求复制全部功能。
- 采用 Blender 建模和 3D 打印制作机壳与物理构件。
- 2026-10-24更新电源需求：内置电池为整机提供直流能源，正常播放即使插电也优先使用电池，不自动旁路到适配器。用户接受电池因未插电使用而低电量时，充电输入参与系统供电以维持播放；外部220V电源主要承担充电用途。电池恢复后回到电池优先模式的切换门限/滞回属于待审核设计。低噪声是目标，不能将电池或边充边播等同于已消除交流干扰。
- 已确认纯电池续航要求：屏幕常亮、正常播放至少1小时。电量按Wh和完整负载路径核算，包含转换损耗、截止电压、保护/安全关机余量及老化；容量、串并数和电池体系尚未选定。普通Power Path不能自动等同于纯电池隔离，纯电池模式须验证充电功率路径实际断开；具体实现与充电器位置尚未冻结。
- 电脑USB仅传音频/必要连接检测，不承担整机供电或充电。保留电脑DAC输入及主控关闭后独立工作要求；VBUS检测与防回灌仍须设计。
- 按自用原型规划，一万元为首版整机预算上限，包含再次打样余量；功放、音箱及通用测试仪器另计。
- 交互采用触摸屏、实体音量旋钮（可方便静音）和手机辅助控制，并提供明确的安全关机入口。
- 音源以 DMP-A6 Gen 2 支持范围为目标，排除机内 SSD；首版以音乐可访问、可播放为要求，允许 App 实现。原生集成和认证协议逐项调查；无法实现的项目必须报告并由用户决定是否接受，不能自动替代。
- 模拟输出性能以对标机为设计目标，首版依据实测验收；格式能力另列清单，最低通过线必须在设计前确认。
- DSD 文件必须可播放，首版允许转为 PCM 并进行音量控制；原生 DSD 为增强目标。PCM 768kHz/32bit、DSD512 为待验证的对标能力，不能以芯片上限代替整机验证。
- 用户明确 AK4499 指 DAC 芯片型号；具体后缀及是否允许替代仍需明确，不能据此认定已批准替换器件。
- 现有保存原理图经 KiCad CLI 导出确认放置 AK4191EQ、AK4499EX、CCHD-957 和五颗 LT3045xDD，证据见 `existing-design-preflight.md`。这是现有工程事实，不代表设计或完整订货号已接受。
- Q19 已接受分层性能要求：原型调试门槛为 XLR SNR ≥115dBA、THD+N ≤0.001%；最终最低验收线为 ≥123dBA、≤0.0002%；对标设计目标为 ≥128dBA、≤0.0001%。测量条件、RCA 及低音量指标另行明确，见 `audio-acceptance.md`。最终最低线未达到则判未通过，由用户决定继续改板或调整目标。
- 保留电脑 USB DAC 输入；光纤、同轴和 HDMI ARC 暂不加入。12V Trigger 输出列为候选，尚非必选；不能替代音频静音保护。
- 外部电脑 DAC 模式必须支持 Android 主控关闭后独立工作；音频与控制子系统独立供电运行，实体旋钮继续控制音量与静音，屏幕和网络可关闭。
- Q20 已确认：首版优先验证树莓派 Android 经 USB 接入独立音频子系统，GPIO I²S 保留为备选。此选择基于集成、电脑输入复用和独立验证便利性，不代表 USB 音质优于 GPIO，也不代表 AK4499 具体版本或器件已定型。
- 机壳最大宽 300 × 深 250 × 高 120mm，允许收紧；打印单件最大 200 × 200 × 200mm，允许分件拼装。打印机型号待定，最终仍需核对实际设备与材料能力。

## 待澄清

- 实际功放/音箱组合及音量控制、故障保护的可测量验收条件。
- 对标音源的完整清单、第三方服务与认证可行性；USB 光驱、蓝牙等未逐项确认的能力应显式列出。
- 屏幕尺寸和手机控制的具体功能。
- 音频格式、对标测量项目和测试条件。
- USB DAC 接口实现和是否加入 12V Trigger 等候选能力。
- 现有可复用设备。

## 当前阶段

2026-10-25用户批准继续推进。已据当前整机方向和电池优先策略形成[分包实施计划](superpowers/plans/2026-10-25-streamer-implementation.md)，先关闭官方资料、功耗/续航、电池路径及测量依赖。批准不等于全部器件参数冻结或采购、接纯后级、生产打样授权；详细设计包仍需具备可审证据。

2026-10-23已形成[整机设计审阅稿](superpowers/specs/2026-10-23-streamer-design.md)，包含模块、控制状态、电源分域、候选芯片、手机控制边界、预算分配及放行条件。新增选择仍为提案，需用户审核后才能形成实施计划；未修改CAD或执行台架测试。

已完成第一轮官方资料调查，形成 `architecture-options.md` 候选比较，并附 Android、AKM、USB 音频及对标音源调查。所有整机功能仍待实机验证。

已确认首版优先验证树莓派 Android 经 USB 接入独立音频子系统；GPIO I²S 与其他主控保留为备选。树莓派 5 为当前推荐验证平台，具体型号和镜像仍需固定。AK4499 版本、USB 接收器与切换电路、音量实现及 PCB 实施方案尚未批准。
