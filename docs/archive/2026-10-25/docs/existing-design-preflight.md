## 已从本地规格确认的设计约束

依据：[AK4191 官方完整手册](https://www.akm.com/content/dam/documents/products/audio/audio-dac/ak4191eq/ak4191eq-en-datasheet-myakm.pdf)，200900053-E-01。

- 第53页 §9.1.3.2：DSD Volume Bypass 模式不提供输出音量控制。纯后级直连不能将该模式视为仍受数字主音量保护。
- 第78页 §9.6：数字衰减寄存器复位到0dB；引脚控制模式也固定为0dB。需要审核 MCU 配置、复位和硬件静音释放顺序，不能把器件默认值当成安全启动音量。
- 第78页 §9.6：数字音量有渐变时间。需将其与模拟静音及电源时序共同验证，不能将软静音请求等同于瞬间断开输出。

这些是规格约束，不是已证实现有电路存在故障。对应整改必须经过连接与配置核查后提出。

## 进入后续设计前

1. 补齐所有核心器件完整官方资料；未选器件和受限文件见 `specs/README.md`。
2. 按本地手册页码建立引脚、电源、时钟和启动状态对照表。
3. 先评审音量与故障静音架构，再设计纯后级直连电路。
4. 再确定 MCU、USB 接收与选择器、I/V/滤波、正负电源等器件；选型时同步归档每个确切型号的官方规格。
