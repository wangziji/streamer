# 整机架构候选方案

日期：2026-10-22。状态：用户已确认 USB 为首版优先验证路线，GPIO I²S 为备选；具体器件、树莓派型号与镜像尚未冻结，本文件不是施工图。

## 需求与现状

目标为一万元以内的自用 Android 流媒体播放器，外置电源，触屏和实体旋钮，支持 USB DAC 输入、XLR/RCA 可变模拟输出及纯后级直连。模拟验收以 `audio-acceptance.md` 为准。KiCad 工程和自定义库已经存在，但尚未通过本轮电路正确性或可制造性评审。

## 候选比较

| 方案 | 结构 | 优点 | 主要代价 | 判断 |
| --- | --- | --- | --- | --- |
| A | Raspberry Pi 5 + Android，经 USB 进入独立音频子系统 | 播放平台与 DAC 解耦，可分别验证；符合树莓派优先 | 社区 Android 的 App/HAL/触屏兼容性需实测；双主机 USB 选择需设计 | 首选验证路线 |
| B | Radxa ROCK 5B + 厂商 Android，经 USB 进入相同音频子系统 | 可利用厂商镜像和板级资料 | 已查官方下载列 Android 12，不能推定具备较新 USB mixer 能力；迁移和持续支持待验证 | A 路线出现明确阻塞后的备选 |
| C | Android 主控 GPIO I²S + 独立电脑 USB 接收，再选择音频路径 | 内置播放减少一个 USB 接收环节 | 强依赖板级音频驱动、主从时钟及跨音源切换；节省器件不代表降低总开发成本 | 首版暂不推荐 |

以上均未获得实机通过证据。平台资料见 `android-platform-feasibility.md`，USB 依据见 `usb-audio-feasibility.md`。

## A 方案的信号链提案

```text
网络 / USB 存储 → Android 主控 ─USB─┐
                                 ├→ 主机选择 → UAC2 接收 → 数字音频前端 → DAC
外部电脑 ───────────────────USB───┘                                  ↓
                                                         I/V + 低通 + 输出级
                                                                     ↓
                                                         音量/静音 → XLR 或 RCA
```

示意图不规定音量器件的位置。数字、模拟或混合衰减需依据实测及故障分析确定。若使用 AK4499EX，数字前端需与其调制数据接口配套，不能将常规 I²S 直接接入 EX；若使用 AK4499EQ，应重新按其接口和参考设计评估。具体料号仍需确认。

## 模块和责任边界

1. **现成主控与屏幕**：负责应用、网络和显示；先做台架验证，不先自研处理器载板。
2. **音频板**：USB 接收、音频时钟、配套数字处理、DAC、I/V、低通及模拟输出；数字音频跨板连接保持短且有明确参考地，分板不等于隔离。
3. **电源与控制板**：按各电压轨电流预算设计转换与稳压；独立 MCU 管理统一音量、静音、输入选择和上掉电。是否与音频板合板在布局评审时确定。
4. **机壳及面板**：屏幕和旋钮位置、散热路径、连接器开孔及分件连接。打印塑料件不承担金属机箱的屏蔽或散热作用；材料、紧固件和局部金属件需独立设计。

## 时钟与音量原则

- 优先评估本地音频时钟和异步 USB；44.1k/48k 系列的时钟生成、分配及切换按最终数字前端要求设计。
- 不先增加无明确作用的重时钟、隔离或 ASRC 芯片；每个器件应对应可验证的问题。
- 独立 MCU 作为整机音量和保护状态的权威；Android、旋钮和电脑音量请求遵守同一上限。
- 电脑 USB 接入、Android 重启或格式切换均不能绕过输出保护；默认静音、故障检测和断电行为需要电路与测试共同验证。
- 低音量噪声与满幅 SNR 分别验收；高标称满幅指标不能证明前级使用时底噪合格。

## 进入原理图前的验证顺序

1. 用现成主控与可测 USB DAC，验证目标 App、NAS、USB 存储、实际采样率及长时间播放。认证和无法支持的音源单独列出，交用户决定。
2. 确认 AK4499 具体型号、渠道报价、配套芯片资料与开发工具。核对现有工程，再决定复用范围。
3. 使用评估硬件验证数字前端、时钟、音量和电脑输入；PCM 768kHz/DSD512 单独取证，不能从通用固件推定。
4. 冻结测试条件、功能覆盖表、BOM 及带修板余量的预算，再提交分板、电源树和原理图设计方案。

一万元为项目上限，并非当前报价承诺；目前尚无完整 BOM、供应商报价或整机功耗预算。若超出预算或出现兼容性阻塞，应回到用户确认取舍。
